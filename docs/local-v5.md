# What `type-v5` does

`from autocgenff.v5 import type_v5` and `autocgenff type-v5 --smiles '...'` run the same installed rule file, `autocgenff/v5/cgenff_v5.rules`. A `Path` / `--input` accepts one SDF or MOL2. The Python API also accepts a `Chem.Mol`. Both start from a sanitized independent structure with explicit H, preserving input atom indices and appending missing H. Give the intended protonation state, bond orders and atom-local formal charges. No residue name, reference mapping, RTF, PRM, or internet access is needed.

`formal_charge` is the **sanitized input formal charge**. `rule_charge` is the rule seed (default zero); `improper_center` flags an `impr` action. Both `sub` and `typ` actions run, before any partial-charge assignment. A type is a diagnostic label, not a partial charge, validated simulation water model, ordered improper, lone pair, or force field. `parameterize(...)` and the CLI without a subcommand retain their previous SMARTS/template and assignment contracts. There is no override file or fallback to SMARTS in local-v5: branches can ask for *another atom's type* while they run, so a relabeling pass after inference would be incorrect.

## Origin and execution

Derived from the MIT-licensed [LigandFF source at 860b17da7e982ef7ab62d993a0e24fda3958bbb6](https://github.com/carlosbaiz/ligandff/tree/860b17da7e982ef7ab62d993a0e24fda3958bbb6): `src/ligandff/typing/{rules.py,engine.py,rules/cgenff_v5.rules}` and `src/ligandff/perception/{rings.py,aromaticity.py}`. Copyright and permission notice are in `autocgenff/v5/LICENSE-LigandFF.txt` in the source and both distributions. No LigandFF runtime, parameter data, external shell scripts or official rules are bundled. LigandFF reconstructed its program from [Part I](https://doi.org/10.1021/ci300363c), MASS descriptions and training references; neither profile is the official CGenFF program.

- This is the complete branching v5 profile, not a list of type names. Start at `main`, take the first matching `typ` or `sub`, expand condition macros, consume distinct neighbors in index order (no backtracking); a nested `ne` excludes the incoming bond. `type` evaluates and memoizes the neighbor's branch on demand. Traces identify each atom's category/line, jump and final leaf. A `?` in the trace is an `altnum` leaf: numbering starts at the lowest index in each connected alternating group, keeps the digit across a multiple bond, and flips it across a single bond. Conflicting numbering or a cyclic dependency raises `AutoCGENFFError`.
- `fc` uses the formal charges on RDKit's sanitized structure; `nb` sums integer bond orders including H. We use RDKit's Kekulé assignment instead of enumerating alternative resonance forms, then run the paper-style ring classifier **on those integer bonds** (not RDKit aromatic flags or SSSR). Cycles of length 3–7 are enumerated on the stripped ring core, sorted by size then indices; each atom keeps its smallest ring, or the three smallest if it has ≥3 ring bonds. `inring` uses bond membership in *all* such cycles. Ring predicates consume matching rings within their condition group. Five- to seven-membered cycles undergo iterative six-π classification; failure to stabilize in 50 passes is fatal. Larger rings are acyclic for these predicates.
- The pinned file has 34 categories, 207 `typ` statements and 161 distinct concrete outputs after expanding both `altnum` digits. The local file has 34 categories, 216 `typ` statements, 42 `sub` statements and 163 distinct outputs. `v5_vocabulary()` audits actual parsed leaves. `tests/test_v5_reference.py` compares them as sets to local v5 **MASS names**, including NG2D1 whose MASS lacks an element column. Result: **163/163 in-scope names**, excluding the two external water types and `LPH`, a zero-mass virtual site. This is vocabulary, not evidence of a correct assignment for every label or input.

## Local chemistry decisions

These changes are in the decision tree, **before** any dependent branch runs:

| Environment | Decision and evidence |
| --- | --- |
| Water and isolated ions | Reject inputs containing any neutral, two-single-bond water O with two terminal neutral H (including isotope labels). Load water via `toppar_water_ions.str`. Neither water label occurs in the ligand rules. Hydroxide, hydronium and elemental O are not treated as water. SOD, CLA, CAL require degree zero and formal charge +1, −1, +2 respectively. They also receive the corresponding rule charge seed. The names/functions come from local v5 MASS. Disconnected counterions are allowed, not inferred or neutralized. |
| B | BG201 is not “any boron”. Require neutral three-coordinate B single-bonded to C and two oxygen ligands with appropriate valence (including terminal O−). BORO/BORN/BONN, their phenyl/ethyl analogues and cyclic BICB motivate this boronic acid/derivative domain. Trigonal boric acid, tetrafluoroborate and hydrides are not inferred from it. |
| Se | SEGD1 requires neutral terminal `Se=C` to a neutral three-coordinate carbon, as in the selenocarbonyl of BSEU. It is not a type for a selenoether or free selenium. |
| Al | ALG1 is specifically four-coordinate `[Al-]` bound to four terminal neutral F by single bonds in the covalent representation of ALF4. F on that typed Al receives FGP1. Disconnected ionic or dative representations are not repaired. |
| Halogens | Separate isolated Cl− from covalent halogens. For carbon-bound halogens, require neutral terminal X with a single bond to carbon. Residue 230020 supplies a distinct FGP1 environment: terminal F on three-coordinate N+ typed NG2R61 in a six-membered aromatic ring. This does not extend to fluoramines or tetrahedral ammonium N. IGR1 is restricted to iodine on aromatic carbon (IODB); there is no corresponding aliphatic iodine type in this vocabulary. `CI`, dihalogens, hydrogen halides and free F−/Br−/I− do not receive organic halogen types. LPH in the IODB RTF is not generated. Inputs with any RDKit-detected radical are rejected as a whole. |
| Aliphatic fluorination | Do **not** impose a blanket H-count test on CG322/CG312/CG302 despite their MASS descriptions: FETH, DFET and TFET show the mono-/di-/trifluoro series, but SM083 explicitly uses CG322 on a tertiary carbon without H and BDFP uses CG312 on C bonded to two F, C and P. Preserve F count and existing small-ring precedence. Do not extend the trifluoro classes to CF4. These examples are not a calibration of every fluorinated scaffold. |
| Primary nitroalkanes | The named NIME/NIPR topologies require the ordered N–O–O–C improper. Set the `impr` action for three-coordinate N+ bound to terminal O− and =O and to neutral methyl or primary alkyl C. Do not generalize this to every `NG2O1` leaf. This fixes the missing mechanical term, not a type-label mismatch. |
| Linear cumulated carbonyls | Route degree-two `O=C=X` to the same carbonyl category without an `impr` annotation: a four-atom improper is impossible at that center. Both CO2 and methyl isocyanate (MICY) have CG2O7 and no improper in the RTF. This removes a false assignment failure, not a physical restraint. |
| Seven-membered enol ether | In 2300N9 the endocyclic `–CH=CH–O–` unit lies between saturated carbons. Only the alkene CH bound to ether O needs an improper (`C10 C9 O11 H24`, exact nonzero PRM match). This is not a blanket change to ring alkenes or furans. **2300N9 is an inspected upstream B1 test example**, used to correct the improper rule, not an unseen validation case. |
| N-amino heterocycles | An exact PRM quartet does not establish that an improper belongs in the topology. In 23000S (ring N adjacent to exocyclic C=NH) omit the amino-N improper and retain the imine-carbon improper. In the aminomethyl lactam pair the neutral side chain (2300BC) lacks the amino-N restraint, whereas its ammonium counterpart (2300BB) retains it. 23000F also retains both the amino-N and carbonyl impropers. These are inspected local RTF distinctions, not a general planarity test. |
| Five-ring conjugated ketone | In the five-membered C(=O)–C=N–O environment of 23001K (B1 train), use the exocyclic CG25C alternating leaf and ketone OG2D3 without a carbonyl improper, as in the RTF. Keep saturated cyclopentanone and lactams on their own branches. |
| Fused cyclic azine | 23002G (B1 train): the 5/7 fusion carbon double-bonded into the endocyclic C=N–N=C sequence is CG2R51; this is not a rule for acyclic azines, whose conjugated carbons retain their alternating types. |

## Local-v5 parameterization

`autocgenff.parameterize_v5` runs the same rules and uses only caller files for force-field data. It does not call named matching. The second argument is a directory or reusable `autocgenff.V5ForceField.from_directory(...)` result. Use the RTF and mechanical PRM from the same additive v5 release. Supply the increment PRM by explicit `increments_path` or as `par_all36_cgenff_increments.prm` in that directory. The validation used [this pinned release file](https://github.com/Lemkul-Lab/toppar_c36_releases/blob/ed3bbdaa4eb0a0152e577480bb0a9d22cd9743c3/charmm/toppar/toppar/par_all36_cgenff_increments.prm), SHA-256 `65e9c2868837bbc6fbfc939f57f37ffdd3317bd4d31303d0672cc153011abde8`. Files are neither bundled nor downloaded. No automatic version reconciliation.

- `atoms` are in explicit-H order with input and rule formal charges, final atomic partial charges when resolved, MASS and typing traces. Reject inconsistent rule seeds **per component**; no charge spreading. `charge_diagnostics.terms` uses each unique covalent path once: bonds, angles and proper torsions only. The first native increment annotation of a Fourier group applies once (subsequent real rows often say `N/A`). One increment transfers from the first endpoint to the next; reversing reverses **and negates** edge transfers. N/A, numeric zero and missing have separate semantics. Unresolved paths prevent a charge assignment. Each match gives original file types, line, orientation, applied values and status.
- `bonds` gives real atom indices and integer bond orders from the exact Kekulé graph used for typing. `terms` contains required bonds, angles, propers, rule-marked impropers, and nonbonded sites, each with target indices/types, status, penalty and all selected mechanical PRM rows. `nbfix` lists relevant base overrides. Order improper neighbors to match available parameters: exact before wildcard before analogy, retaining the center, refusing tied distinct type orders. Same-type neighbors use index order. Exact proper torsions around CG1N1/CG1T1/CG1T2 take precedence; without an exact term they appear in `omitted_linear_propers`, not in the mechanical inventory. Their charge paths are **not** omitted. Export must not let AUTO regenerate omitted terms.
- `local-v1/observed-acyclic-alkyl` is a **provisional, intentionally narrow** substitution model. Inspired by LigandFF's `params/penalties.py` single-substitution observations, it uses no bundled matrix or similarity fallback. Read `from <types>, penalty=...` annotations of actual local PRM bond/angle/proper groups, requiring an existing exact source row, an unambiguous one-position mismatch, and both labels in the ordinary acyclic saturated carbon family (CG301/311/321/331) or alkyl-H family (HGA1/2/3). Recover a directional cost by dividing by the role weight (10 inner, 1 outer); take the mode by independent group, lower cost on a tie. `ff.substitution_evidence` gives matrix, direction, cost and a supporting PRM line. `best_analogy` then scores mechanical vs charge candidates independently. No substitution of LJ sites, charge states or unobserved type pairs. These are not official penalties or newly fitted force constants.
- No halogen virtual site is silently generated. The v5 RTF contains colinear LPH sites for CLGR1/BRGR1/IGR1, and both site and no-site examples for aliphatic CLGA1/BRGA1. Ligands with these host types are **incomplete**: the real-graph increment diagnostic has not been split between host and site, and atom partial charges are withheld. No unverified placement or I–LP covalent bond is invented. Missing masses/parameters/charges and explicit isotope masses also block completion. `.is_complete` means model coverage only.

### End-to-end checks

Set `AUTOCGENFF_V5_INCREMENTS` to the above local file, optionally `AUTOCGENFF_V5_DIR` to a nonstandard base directory, and run `python -m pytest tests/test_v5_assignment.py`. Independently computed expected per-atom charge outputs use the pinned LigandFF `IncrementTable.from_prm` and `charges.increments.assign_charges` on **RTF atom types and bonds** in the test's named correspondence, with C2:-1 for acetate, NZ:+1 for methylammonium and zero elsewhere. Use both single and double RTF bonds (including `DOUB` in CO2). These are increment-model comparisons, not agreement with hand-optimized RTF charges. For six exact cases the test also independently enumerates every covalent path on the RTF graph and checks ordered improper types. Neopentyl alcohol exercises three non-exact mechanical and charge paths with reported sources. Of a deliberately targeted ten-molecule diagnostic panel, **7/10 complete** (those seven cases); acetonitrile lacks native increments for three linear torsion paths, iodobenzene and chloroethane are blocked for LP semantics. Mixed ligand–water is an additional whole-input rejection, not a partly successful ligand assignment. This is a smoke panel, not a representative success rate.

A separate improper-inventory regression checks all atom labels, covalent edges, marked centers and the full set of **ordered atom quartets** against the named MICY, 2300N9, 23000S, 23000F, 2300BC and 2300BB residues. All six assignments complete with the pinned local inputs; all required impropers are exact nonzero base PRM matches. Their CLI streams also loaded in PSFGEN with 0, 1, 1, 2, 1 and 2 impropers respectively. No residue identity is passed to inference.

## Stream export

`autocgenff assign-v5 --help` describes the single-invocation workflow; the corresponding Python API is `write_v5_stream(assignment, path, residue_name="LIG")`. See the [CLI and API examples](../README.md#parameterize-a-ligand-in-one-offline-invocation). Keep the JSON audit: it records names/indices, traces, formal vs partial charges, bond orders, source paths/lines, orientation per row, penalties, omissions, issues and, for the CLI, whether a stream was written. A complete assignment can still fail export.

- The stream appends one connected residue with one `GROUP`, explicit `BOND`/`DOUBLE`/`TRIPLE` and ordered `IMPR`, `AUTO ANGLES DIHE`, and no terminal patches. Explicit hydrogen atoms are included. Available MOL2 names, SDF aliases/atom labels or RDKit atom names/PDB names survive; unnamed atoms receive element+ordinal names avoiding all reserved names. CHARMM names are case-insensitive. Ambiguous, duplicate or nonrepresentable names are errors, never silently truncated (writer limit: 1–4 ASCII letters/digits, beginning with a letter). This is a topology for use with a matching coordinate model, **not** a round trip of stereochemistry, residue metadata or geometry. No coordinates or IC building instructions are emitted.
- The writer reloads the base RTF/PRM, checks for residue/patch or parameter collisions, and emits **only** missing bonded keys assigned by analogy. Full reversal of the atom quartet preserves its signed dihedral; all multiplicities/phases are emitted together in one consistent orientation. Independent charge transfers are not Fourier terms. Exact and wildcard hits, native LJ, 1–4 and NBFIX stay in the base. The exact-only stream has no parameter block. Multiple ligands' additions share a CHARMM global parameter namespace: inspect for incompatible keys in *other* streams before loading them together. These are not isolated per-residue overrides.
- It reloads the serialized topology and delta blocks, reconstructs the graph and required AUTO inventory, checks ordered impropers, and verifies the serialized atom charges and net sum before replacing a `.str` on the same filesystem. It will not replace an unrelated stream. Missing parameters/charges, unresolved lone pairs and omitted linear propers cannot silently become a shorter topology. Linear omissions **block** AUTO export rather than adding a dummy parameter or letting the engine regenerate an undefined torsion. CO2, which has no proper path, is supported. No bond geometry, exclusions, rigid water, virtual sites or constraints are inferred.

## Limits when interpreting a successful run

Input-dependent resonance, tautomer, protonation, aromatic fused-ring classification, atom order in tied rings/greedy matches and alternating-label phase can change exact maps. No global minimum-penalty resonance search, bond-order repair, geometry inference, ion coordination, metal parameterization or stereo-specific parametrization. Rare-element predicates are positive applicability tests, not a general inorganic model. An unknown atom yields `atom_type=None`, `errors` and `is_complete=False`; other atoms' labels in such a result are diagnostic only. Invalid structures, radicals and nonconvergence are errors, not partial successes. Some inherited categories still have generic leaves: a complete map does not certify that the molecule is in-domain. Unusual valence/charge states, hypervalent or multicenter bonding, macrocycles, planar heterocycles and conjugated systems need independent chemistry review. The exact mismatches above are real limits; static vocabulary coverage does not remove them.
